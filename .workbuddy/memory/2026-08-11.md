## Bug 修复（同日下午）
- 问题①：首次打开预置了两个示例项目+示例数据，用户不需要。改为空看板起步：去掉 seed()，STORAGE_KEY 升到 `kanban.v2`（忽略旧 v1 种子数据），无数据时返回 `{projects:[]}`；新增空状态页（renderEmpty，带「＋ 新建项目」按钮），无项目时禁用新建任务/文档并重定向到建项目。
- 问题②：任务/文档弹窗的「取消」和「✕」点击无反应。
  - 根因（用 jsdom 复现）：bindClose 用 `[id$="CancelBtn"]` 选取消按钮，但任务弹窗取消按钮 id 是 `cancelBtn`（小写 c），大小写敏感匹配不到 → querySelector 返回 null → `.onclick=` 抛错 → 脚本在 bindClose(modal) 处中断，导致后续 doc 弹窗的关闭绑定与最后的 `render()` 都未执行。
  - 修复：给四个取消按钮加统一类 `.modal-cancel` 并用它绑定；给四个 ✕ 按钮加 `type="button"`（避免默认 submit）；bindClose 改为空安全。修复后 0 脚本错误，任务/文档弹窗的取消与 ✕ 均可正常关闭，render 正常执行。
- 验证：用 jsdom 写 test_close.js 模拟点击，确认空状态、四个关闭按钮、建项目后渲染均通过。
